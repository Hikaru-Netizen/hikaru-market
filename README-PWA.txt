HIKARU MARKET — PWA READY FOR NETLIFY

This package keeps the existing Hikaru Market website and adds:
- manifest.webmanifest
- service-worker offline caching
- PWA icons generated from the supplied Hikaru Market logo
- favicon and Apple touch icon
- Netlify configuration

DEPLOY TO NETLIFY
1. Upload this ZIP to a Netlify site, or extract it and deploy the folder.
2. The site must be served over HTTPS (Netlify provides HTTPS).
3. Open the site on Android Chrome and use "Install app" / "Add to Home screen".
4. The installed app name is "Hikaru Market".

No WhatsApp links were changed.
