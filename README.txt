HIKARU MARKET WEBSITE
======================

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka index.html di browser.
3. Website sudah menggunakan gambar yang diberikan.
4. Banner bergeser otomatis setiap 4,5 detik.
5. Semua tombol "Minat" mengarah ke WhatsApp:
   https://wa.me/62887437451298

Untuk mengganti nomor WhatsApp:
- Buka index.html.
- Cari: 62887437451298
- Ganti semua kemunculannya dengan nomor bisnis baru (format internasional tanpa +, spasi, atau tanda -).

Untuk mengganti produk/harga:
- Edit judul dan deskripsi pada bagian <article class="product">.
- Jika nanti ingin sistem stok, pembayaran, login admin, atau database, website ini bisa dikembangkan lebih lanjut.
